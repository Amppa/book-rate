評分來源說明

※ 除了 Open Library 和 Google Books，其他來源無提供 API，需用爬蟲爬分數，可能會因為網頁改版而失效。

Open Library 千萬級 ★☆☆☆☆ 可 官方 API 最佳的書籍資料庫平台，提供 Edition(Work) 對應。缺點是有些書名因翻譯而有遺漏。
Google Books
Google Play		 千萬級 ★★☆☆☆ 無 書名-官方 API
分數-Web 擷取		 分成google books和google play。前者是書籍資料庫(適合用作書名搜尋)，後者是電子書書店(有評分資料)。
Goodreads 未知 ★★★★★ 可 Web 擷取 全球最大的讀者社群(1.5億用戶)，英文作品評價極多(也偶有灌水、抹黑)。2006創立於舊金山，2013被Amazon併購，2016併購Shelfari。數據與Amazon分開。
StoryGraph 未知 ★★★★☆ 可 Web 擷取 新興讀者社群，goodreads的競爭者。2019，一名牛津大學文組黑人女性創立，主打更貼近讀者。注意：不支持中文書名！
Amazon (US) 千萬級 ★★★☆☆ 無 Web 擷取 世界最大的書籍銷售平台。商品評價，以版本為單位，不同語言不合併。當Web改版，爬蟲會失效。
Amazon Japan 百萬級 ★★☆☆☆ 無 Web 擷取 日本 Amazon。
豆瓣讀書 百萬級 ★★★★★ 可 Web 擷取 中國最大的讀者社群，書評多，用戶高達2億。通常依出版社與 ISBN 分開。2005成立。
Readmoo讀墨 十萬級 ★★★☆☆ 無 Web 擷取 台灣最大的電子書平台，繁體中文書評多。
libraryThing 未知 ★☆☆☆☆ 可 暫不支援 20年歷史的書籍網，2006美國波特蘭成立。Cloudflare 擋爬蟲（嚴格），有提供書名查editions服務（需API key）。網友評分資訊少，且無API。
aNobii 未知 ★★☆☆☆ 可 暫不支援 2006年香港創立，Web2.0時代最大的中文讀書社群。可惜2010被英國出版社收購後每況愈下
Bookmeter 未知 ☆☆☆☆☆ 無? 暫不支援 日本的讀書社群網站，2008成立。以心得、評論為主，沒有打分。2014被日本出版社角川買下。
